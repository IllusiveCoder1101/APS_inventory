Application Overview

The APS Inventory Management System helps track and manage all types of inventory across the institution. It is divided into three main categories, each handling a different kind of asset.

C

Consolidated Items

High-level categories that group assets by type (e.g., Furniture, IT Equipment, Sports Gear). Each category tracks the total financial value including purchases, depreciation, and serviceable/unserviceable breakdowns.

E

Expendable Items

Consumable supplies that get used up over time (e.g., paper, markers, cleaning supplies). Tracked monthly with opening stock, purchases, and consumption. Transactions are recorded for each issue or receipt.

NE

Non-Expendable Items

Permanent assets with a long lifespan (e.g., computers, furniture, vehicles). Split into Government Funded (GF) and School Funded (SF). Each item is linked to a consolidated category and has detailed tracking for quantity, condition, and value.

How They Connect

Every Non-Expendable Item belongs to a Consolidated Category. When you add, edit, or remove a non-expendable item, the parent consolidated category's financial totals are automatically updated. Expendable items are independent and tracked on their own monthly cycle.

Dashboard

The dashboard provides a quick snapshot of your entire inventory at a glance. It is the first screen you see after logging in.

Stats Overview

Four summary cards appear at the top:

1
Consolidated Value

The total financial value of all consolidated categories combined. Gives a quick sense of the institution's total asset worth.

2
Expendable Stock

The current net stock of all consumable items. Calculated as: opening balance + purchases made - items consumed this month.

3
Non-Expendable (Gov)

Total count of all government-funded permanent assets currently tracked in the system.

4
Non-Expendable (School)

Total count of all school-funded permanent assets currently tracked in the system.

Charts

Five interactive charts provide visual insights:

  • Consolidated Value Breakdown — An area chart showing the top 10 highest-value categories with their previous value, serviceable value, unserviceable value, and depreciation side by side.
  • Expendable Stock Flow — A doughnut chart showing the proportion of previous stock, new purchases, and items consumed this month.
  • Items by Fund Type — A pie chart showing how many consolidated categories fall under Government Fund vs School Fund.
  • Serviceable vs Unserviceable — A pie chart showing the total count of non-expendable items that are in working condition versus those that are not.
  • Top 10 Highest Value Assets — A horizontal bar chart listing the 10 most expensive individual non-expendable items by total value.

Quick Tables

Below the charts, four preview tables show the first 5 items from each section (Consolidated, Expendable, Non-Expendable GF, and Non-Expendable SF). Each table has an "Explore More" button that takes you to the full listing page for that section.

Consolidated Items

Consolidated items are the top-level categories that group your permanent assets. Think of them as folders — each non-expendable item must belong to one of these categories.

What Each Category Tracks

AppendixA unique short code for the category (e.g., "A1", "A2")
Fund DetailsWhether this category is Government Funded (GF) or School Funded (SF)

PurchasesTotal value of new items added to this category this year

How to Use

1
View All Categories

The main page shows all consolidated categories in a table. You can search by name, appendix, or fund type. Use the fund detail filter buttons to show only GF or SF categories.

2
Add New Categories

Click "New Items" and upload an Excel file. The system will read the spreadsheet and create new categories. If a category with the same appendix or property head already exists, it will be rejected.

3
View & Edit Details

Click "View More" on any row to see full details. You can edit any field except the present value (which is always calculated automatically). If you change the appendix, all linked non-expendable items will be updated as well.

4
Delete Categories

Select one or more rows by clicking on them, then click "Delete Items". Deleting a category will also remove all non-expendable items linked to it.

5
Download Report

Click "Download" to export all categories as a formatted Excel file with styled headers and borders.

Important

Deleting a consolidated category will permanently remove all non-expendable items that belong to it. Make sure to reassign items to a different category before deleting if you want to keep them.

Expendable Items

Expendable items are consumable supplies that get used up and need regular restocking. The system tracks them on a monthly cycle — each month starts fresh with a new opening balance.

How the Monthly Cycle Works

Opening Balance(carried from last month)
+
Purchases(new stock added)
-
Utilized(consumed this month)
=
Final Balance(becomes next month's opening)

Managing Items

1
View All Items

The main page lists all expendable items with their name, opening stock, purchases, and consumption. Use the search bar to find specific items by name.

2
Add Items via Excel

Upload a spreadsheet to add new consumable items. Each item needs a unique name, unit of measurement, and opening quantities.

3
View Item Details

Click "View More" to see the full detail page for an item, including all transaction records (issues and receipts) for the current month.

Recording Transactions (Issues)

Each expendable item has a transaction log that records every time stock is received or issued out:

Receiving Stock (RV)

When new stock arrives, record it as a receipt. This adds to the purchase quantity for the month. Enter the date, RV number, source, and quantity received.

Issuing Stock (IV)

When supplies are given out to a class, office, or department, record it as an issuance. This adds to the utilized quantity. Enter the date, IV number, recipient, and quantity issued.

End of Month

At the end of each month, the system automatically rolls over. The final balance becomes the new opening balance for the next month, and all transaction records from the previous month are cleared. A summary email is generated and sent before the rollover happens.

Non-Expendable Items

Non-expendable items are permanent assets that have a long lifespan — things like computers, vehicles, lab equipment, and furniture. They are split into two sections based on how they were funded.

Government Funded (GF)

Items purchased using government grants and official funding. These typically include infrastructure, IT equipment, vehicles, and large installations.

School Funded (SF)

Items purchased using the school's own funds. These often include sports equipment, library resources, workshop tools, and extracurricular supplies.

How to Use

1
Browse & Filter

The list page shows all items for the selected fund type (GF or SF). Use the search bar to find items by name. Use the category filter buttons to narrow down to specific consolidated categories.

2
Add Items via Excel

Upload a spreadsheet with item details. The system validates each item — the category must exist in consolidated items, and item names and LP numbers must be unique.

3
View & Edit Details

Click "View More" to see full details including computed values like total bid value and depreciated price. You can edit any field. If you change the category, values are moved from the old consolidated category to the new one.

4
Delete Items

Select items and delete them. The parent consolidated category's totals are automatically adjusted to reflect the removal.

5
Download Report

Export all items as a formatted Excel file. Items are organized into separate sheets by category, with calculated fields included.

Automatic Value Updates

Whenever you add, edit, or delete a non-expendable item, the system automatically recalculates the parent consolidated category's totals. You never have to manually update consolidated values — they always stay in sync.

Remarks System

The remarks system allows you to mark non-expendable items for disposal. When items are no longer needed or are beyond repair, you can tag specific quantities for auctioning, destroying, or marking as used.

Three Types of Remarks

Auction

Items to be sold off through an auction process. The marked quantity is removed from the active inventory count.

Destroy

Items that are damaged beyond repair and need to be disposed of. These are permanently removed from the usable count.

Used

Items that have been consumed or fully utilized. Marked as no longer available in the inventory.

Adding a Remark

1
Open Item Details

Navigate to the detail page of any non-expendable item.

2
Choose Type & Quantity

Select whether you want to mark items as Auction, Destroy, or Used. Enter how many units to mark. Then choose whether these units should come from the Serviceable pool or the Unserviceable pool.

3
System Updates

The system deducts the quantity from your chosen pool and updates the consolidated category totals accordingly. A badge appears on the item showing the remark.

Removing a Remark

1
Click the Badge

On the item detail page, click the remark badge you want to remove.

2
Choose Restore Pool

A confirmation dialog asks where to restore the items — back to Serviceable or Unserviceable. This lets you correct the inventory if items were repaired or reassessed.

3
System Restores

The quantities and financial values are added back to the appropriate pool, and the consolidated category totals are updated.

Monthly Process

At the end of each month, the system performs two automated tasks to prepare the inventory for the new month.

1
Email Report Generation

The system generates a summary email containing the current state of all inventory. This serves as a monthly snapshot and audit trail before any rollover happens.

2
Expendable Rollover

For expendable items, the final balance (opening + purchased - consumed) becomes the new opening balance for the next month. All individual transaction records from the previous month are cleared, giving a fresh start.

3
Yearly Rollover (Annual)

Once a year, consolidated categories go through a yearly adjustment. The present value becomes the new previous year value, and purchase/depreciation fields are reset for the new financial year.

No Manual Action Needed

Both the monthly and yearly rollovers are fully automated. You do not need to trigger them manually. The system handles everything in the background at the scheduled time.
